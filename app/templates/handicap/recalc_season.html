What this does

Recomputes the Handicap Index for every active player in this season, using each player's current pool of completed rounds (the standard windowed/dropped/averaged differential calculation) — the same result you'd get if a player's handicap were being calculated fresh today. This updates each player's current handicap only.

It does not retroactively correct past rounds' point-in-time handicap history, net scores, or match points — for that, use Rebuild Full Timeline instead (league-wide, walks every round chronologically).

Typical reason to run this: scores were added/edited for this season, or a handicap-related league setting changed, and current handicaps need to reflect that.
