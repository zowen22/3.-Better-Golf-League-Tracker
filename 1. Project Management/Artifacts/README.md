# Artifacts

Archived copies of standalone HTML artifacts originally published/hosted on
claude.ai (interactive mockups, side-by-side option comparisons, before/after
visuals) that a session referenced while making a decision. Kept here so the
underlying comparison survives after the hosted artifact itself is gone —
this is the durable copy.

Not code, not directly linked into the app — reference material for
Decisions Log entries and Plans in `2. Project Overview.md` / `Plans/`.

Saved here as `<YYYY-MM-DD>-<slug>.html`. Add a pointer from
`4. Technical Reference.md` or the relevant Session Log entry when you add
a file here, so a future session can discover it exists (see the 2026-07-31
PM docs audit, finding 1.3 — this folder previously had zero cross-references
anywhere else in the PM tree).
