# Audits

Findings-only investigations into an existing area of the app — structure/UX
reviews, bug sweeps, feature-parity assessments. Audits report; they don't
change code themselves (a following session or Handoff does that).

Checked at the start of every session (see `CLAUDE.md` → Open Audits). A
file with `Status: Open` or `Status: In Progress` is an active work item
alongside the WP backlog.

Saved here as `<YYYY-MM-DD>-<slug>.md`.

**Status values in practice** (per the 2026-07-31 PM docs audit, finding
1.4): CLAUDE.md's own instruction only names two — `Open` and
`In Progress` — but this folder has also used `Complete`, `Planned`,
`OBSOLETE`, and free-text variants that embed commentary in the status
line itself. Free text is fine when it adds real information, but always
lead the `Status:` line with one of the plain values above (or `Complete`)
so a mechanical scan for `Open`/`In Progress` doesn't miss a real open item
phrased differently.
