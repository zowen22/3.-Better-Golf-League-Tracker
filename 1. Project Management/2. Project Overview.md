# Project Overview

*Generated from Problem Statement on: 2026-06-11*

-----

## Summary

BetterGolfLeagueTracker is a self-hosted, multi-tenant golf league management web app built in Python/Flask. It targets full feature parity with golfleaguetracker.com and is currently deployed on Render (Supabase Postgres backend), live at https://bettergolfleague.com (custom domain via Cloudflare Registrar, went live 2026-07-15; the original https://bettergolfleaguetracker-oceb.onrender.com Render URL still works as a fallback). The long-term goal is a paid SaaS platform.

## Scope

### In:
- Full league lifecycle: seasons, teams, schedules, scores, standings, playoffs, skins
- Multi-tenant isolation (each league fully independent)
- Admin panel + member views + dual auth (shared league password + individual accounts)
- Self-hosted and cloud-hosted deployment paths
- PostgreSQL backend (migrated from SQLite)

### Out:
- Native iOS/Android apps (mobile web only; iOS app is future backlog)
- USGA slope/rating handicap system (par-based differential by design)
- ~~Multi-league user accounts (deferred)~~ — scoped in 2026-08-11, see Decisions Log; moved to Work Packages backlog, no longer deferred
- Extended content features (image gallery, document library)
